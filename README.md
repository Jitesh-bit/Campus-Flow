# 🎓 CampusFlow

### Your Academic Navigator

> **Everything you need for college, in one flow.**

CampusFlow is a modern student productivity and academic-management platform designed to bring **timetables, assignments, exams, attendance, tasks, notes, announcements, and academic performance** together in one personalized dashboard.

Instead of jumping between different tools and sources, CampusFlow gives students a clear answer to one question:

### **"What do I need to focus on today?"**

---

## ✨ Why CampusFlow?

College life comes with information scattered everywhere — classroom announcements, assignment deadlines, exam schedules, attendance records, notes, and personal tasks.

CampusFlow brings all of that together into one simple interface.

**With CampusFlow, students can:**

* 📅 Manage their timetable
* 📝 Track assignments and deadlines
* 🧪 Keep up with upcoming exams
* 📊 Monitor attendance
* ✅ Manage personal tasks
* 📚 Organize study notes
* 📢 Stay updated with announcements
* 📈 Track academic performance
* 🔔 Keep important notifications in one place

---

## 🚀 Features

### 📊 Student Dashboard

A personalized overview of your academic life.

* Today's classes
* Upcoming assignments
* Pending tasks
* Upcoming exams
* Attendance summary
* Academic performance
* Recent announcements
* Notifications

---

### 📅 Timetable

Keep your entire weekly schedule organized.

* Day & week views

---

### 📝 Assignments

Never lose track of a deadline again.

* Identify overdue work

---

### 🧪 Exams

Know what's coming before it arrives.

* Subject and exam type

* Upcoming exam countdown
* Midterms, finals, quizzes, practicals and more

---

### 📊 Attendance

Keep an eye on your attendance before it becomes a problem.

* Overall attendance
* Subject-wise attendance
* Present / absent records
* Attendance percentage
* Attendance trends
* Low-attendance warnings

---

### ✅ Task Manager

A simple productivity system for everything outside your academic schedule.

* Create tasks
* Set priorities
* Add due dates
* Search and filter
* Mark tasks complete

### 📚 Notes

Keep your study material organized by subject.

* Create notes
* Edit and delete notes

### 📈 Academic Performance

Understand how you're performing academically.

### 📢 Announcements

Stay updated without hunting through different platforms.

## 🎨 Design Philosophy

CampusFlow follows a **modern student-focused SaaS aesthetic**.

The interface focuses on:

* Clean layouts
* Clear information hierarchy
* Responsive design
* Minimal visual clutter
* Consistent spacing
* Subtle animations
* Accessible UI
* Useful empty and loading states

The goal isn't to make the dashboard look complicated.

It's to make it **useful within seconds**.

## 💻 Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/Jitesh-bit/Campus-Flow.git
```

### 2. Navigate into the project

```bash
cd Campus-Flow
```

### 3. Install dependencies

```bash
npm install
```

Or with Bun:

```bash
bun install
```

### 4. Start the development server

```bash
npm run dev
```

The application will be available on your local development server.
